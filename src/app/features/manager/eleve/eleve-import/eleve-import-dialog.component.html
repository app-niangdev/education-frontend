Formats acceptés : .xlsx, .xls, .csv

La première ligne du fichier doit porter les noms des colonnes. Les intitulés courants sont reconnus automatiquement (« Nom », « Prénom », « Date de naissance », « Sexe »…) ; les colonnes inconnues sont ignorées.

Fratrie : renseignez le NIN du tuteur pour que les frères et sœurs partagent une même fiche tuteur — et donc un seul accès famille. Sans NIN, chaque ligne crée son propre tuteur.
